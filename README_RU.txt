ANIWorld — статический каталог аниме с Vercel Function для публичного AniLiberty API.

## Что подключено

- Каталог, поиск, шесть вариантов озвучки и встроенный плеер.
- Поиск и карточки AniLiberty идут через фиксированные маршруты `/api/anilibria`; прокси не принимает произвольные URL и используется для метаданных.
- Ручной источник серии поддерживает прямой MP4, HLS (.m3u8) и iframe, если владелец хостинга разрешает встраивание.
- Поля media из ответа каталога не подставляются в плеер автоматически: API-ответ не подтверждает право на воспроизведение или фактическую доступность потока. Ответ HTTP 403 остаётся блокировкой; приложение не ищет обходной endpoint.
- Автоматически подтверждённых потоков для AniLibria, AniDub, Студийной Банды, AnimeVost, Dream Cast и Reanimedia не добавлено. Ссылки нужно указывать вручную только при наличии права их использовать.

## Как сейчас работает источник

В карточке аниме выбери серию и озвучку, открой «Настроить источник серии» и введи HTTPS-ссылку. Для MP4/HLS выбери прямое видео; для страницы плеера — iframe. Хост видео должен разрешать воспроизведение и CORS для HLS; хост iframe должен разрешать встраивание. Если встраивание запрещено, можно открыть сохранённую страницу источника в новой вкладке.

Пока в проекте настроено только хранение в `localStorage`: ссылка доступна только в том же браузере и на том же устройстве. Это не общая база, поэтому другие посетители и устройства её не увидят. Вход в аккаунт в интерфейсе — демонстрационный и не даёт авторизации.

## Общее хранилище источников

Проект поддерживает общий каталог ссылок через Vercel Function `/api/sources` и Upstash Redis. GET читает общий список; POST и DELETE требуют отдельный токен редактора. Если Redis не подключён, сайт продолжает использовать прежний `localStorage` и показывает, что сохранение доступно только в текущем браузере.

### Что нужно настроить в Vercel

1. В Vercel открой проект `aniworld1`, раздел Storage/Marketplace и подключи Upstash Redis. Интеграция Vercel добавляет серверные переменные `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN`; токен Redis должен оставаться на сервере.
2. В Settings → Environment Variables добавь `ANIWORLD_SOURCE_ADMIN_TOKEN` со случайным длинным секретом (не менее 32 случайных символов). Выбери Production; Preview добавляй только если редакторам нужно менять источники в preview-развёртываниях. Не добавляй этот токен в код или публичные переменные `NEXT_PUBLIC_*`.
3. После подключения Redis и добавления токена запусти новый production deployment, чтобы Function получила переменные среды.
4. На сайте выбери аниме, серию и озвучку, открой «Настроить источник серии», вставь HTTPS-ссылку, выбери MP4/HLS или iframe, введи токен редактора и нажми «Сохранить в общей библиотеке». Браузер не сохраняет токен.

При подключённом Redis записи доступны всем посетителям сайта; менять и удалять их могут только владельцы токена редактора. API ограничивает список 1000 записями и принимает только HTTPS URL. Ссылки добавляй лишь если у тебя есть право их использовать. Ссылки на видео не ищутся и не подставляются автоматически.

В этой рабочей среде Vercel-плагин найден, но не установлен/не подключён, а подключённого Upstash хранилища нет. Поэтому создать базу и записать серверные переменные здесь нельзя; выше перечислены оставшиеся действия в Vercel. Код `/api/sources` уже готов и не требует установки npm-пакетов.

Полезные официальные страницы: [Vercel Marketplace Storage](https://vercel.com/docs/marketplace-storage), [Vercel Node.js Functions](https://vercel.com/docs/functions/runtimes/node-js), [Upstash Redis REST API](https://upstash.com/docs/redis/features/restapi), [переменные Upstash Redis](https://upstash.com/docs/redis/howto/connect-with-upstash-redis).

## Развёртывание и проверка

Проект разворачивается из GitHub в Vercel; каталог `api/` публикует serverless functions. После деплоя проверь:

- `/api/anilibria?action=search&query=Frieren` — JSON с метаданными, если upstream AniLiberty доступен;
- `/api/sources` — до настройки Redis вернёт `configured: false`; после подключения Redis вернёт общий список и признак доступности записи;
- в карточке аниме проверь выбор серии и все шесть озвучек; при отсутствии разрешённого источника плеер сообщает об этом и не загружает media-ссылки из метаданных каталога;
- при включённой общей записи неверный токен должен получить отказ, а локальное сохранение остаётся доступно, если база ещё не настроена.
