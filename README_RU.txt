ANIWorld — версия с серверным прокси поиска AniLibria для Vercel

Что исправлено:
- Запросы поиска/карточки AniLibria идут через /api/anilibria, а не напрямую из браузера. Это может устранить браузерную ошибку CORS.
- Прокси разрешает только два фиксированных endpoint AniLibria и не принимает произвольные URL.
- Сохранены каталог, шесть озвучек, встроенный плеер и панель ручного источника.

ВАЖНО: загрузка через Vercel Drop может опубликовать только статические файлы и не развернуть /api function. Чтобы API работал, импортируйте папку/проект через Git repository или используйте Vercel CLI (`vercel deploy --prod`) из этой папки. В проекте должны присутствовать index.html, vercel.json и api/anilibria.js.

После публикации проверьте /api/anilibria?action=search&query=Frieren. Должен вернуться JSON. Если будет ошибка 502/500, значит Vercel Function или upstream API недоступен.

Ограничения:
- Прокси исправляет только способ обращения к API; он не гарантирует наличие конкретного аниме или доступность видеопотока.
- Прямое воспроизведение зависит от реального потока, CORS/правил хостинга и разрешений правообладателя.
- Сохранённые вручную ссылки по-прежнему хранятся локально в браузере. Общая база источников и защищённая админ-панель здесь ещё не настроены.
- Для AniDub, Студийной Банды, AnimeVost, Dream Cast и Reanimedia подтверждённые потоки не добавлены автоматически.
