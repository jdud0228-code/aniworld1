ANIWorld — статический каталог аниме с Vercel Function для публичного AniLiberty API.

## Что подключено

- Каталог, поиск, шесть вариантов озвучки и встроенный плеер.
- Поиск и карточки AniLiberty идут через фиксированные маршруты `/api/anilibria`; прокси не принимает произвольные URL и используется для метаданных.
- Ручной источник серии поддерживает прямой MP4, HLS (.m3u8) и iframe, если владелец хостинга разрешает встраивание.
- Поля media из ответа каталога не подставляются в плеер автоматически: API-ответ не подтверждает право на воспроизведение или фактическую доступность потока. Ответ HTTP 403 остаётся блокировкой; приложение не ищет обходной endpoint.
- Автоматически подтверждённых потоков для AniLibria, AniDub, Студийной Банды, AnimeVost, Dream Cast и Reanimedia не добавлено. Ссылки нужно указывать вручную только при наличии права их использовать.

## Как сейчас работает источник

В карточке аниме выбери серию и озвучку, открой «Настроить источник серии» и введи HTTPS-ссылку. Для MP4/HLS выбери прямое видео; для страницы плеера — iframe. Хост видео должен разрешать воспроизведение и CORS для HLS; хост iframe должен разрешать встраивание. Если встраивание запрещено, можно открыть сохранённую страницу источника в новой вкладке.

Пока в проекте настроено только хранение в `localStorage`: ссылка доступна только в том же браузере и на том же устройстве. Это не общая база, поэтому другие посетители и устройства её не увидят. Вход в аккаунт в интерфейсе — демонстрационный и не даёт авторизации.

## Что нужно для общего хранилища источников

В репозитории пока нет API для чтения/записи источников, базы данных или авторизации редактора. Для общей библиотеки нужно:

1. Подключить к проекту Vercel постоянное хранилище (например, Upstash Redis через Vercel Marketplace).
2. Настроить в Vercel серверные переменные `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN`. Стандартный токен базы хранить только на сервере, не в браузере.
3. Добавить защищённый маршрут `/api/sources`, который сохраняет URL по ключу «аниме + серия + озвучка» и проверяет права редактора. Для токена записи можно добавить серверную переменную `ANIWORLD_SOURCE_ADMIN_TOKEN`; одного подключения базы недостаточно без защиты записи.
4. Обновить интерфейс так, чтобы он читал и записывал через этот маршрут, затем заново развернуть Vercel-проект.

Переменные сами по себе не включат общий режим: сейчас маршрут `/api/sources` и код авторизации отсутствуют. Проверить переменные Vercel из этого репозитория нельзя; в репозитории нет конфигурации общей базы. См. [Vercel Marketplace Storage](https://vercel.com/docs/marketplace-storage) и [Upstash Redis REST API](https://upstash.com/docs/redis/features/restapi).

## Развёртывание и проверка

Проект должен быть импортирован в Vercel как Git-репозиторий, чтобы папка `api/` разворачивалась как serverless functions. Ручная загрузка статических файлов через Vercel Drop может не публиковать функции. После нового деплоя проверь:

- `/api/anilibria?action=search&query=Frieren` — JSON с метаданными, если upstream AniLiberty доступен;
- открыть карточку, выбрать серию и нажать «Смотреть» — если нет ручного источника, интерфейс сообщает, доступны ли данные серии и видеопоток;
- в панели ручного источника явно указано, что сохранение локальное, пока серверное хранилище не настроено.

Прямое воспроизведение зависит от действующей ссылки, разрешений источника, CORS и правил встраивания. Метаданные каталога не являются ссылкой на видео.
